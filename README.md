# othello-ai

対戦できるオセロAIと、対局結果から弱点を解析するツールです。
「オセロで強くなる」ための学習ループ（対局 → 解析 → 課題の特定 → ドリル）を支援するために作りました。

## 構成

- `othello/engine.py` — 盤面・合法手・反転処理と、読みやすいリファレンス実装の探索AI
- `othello/fast.py` — ビットボードによる高速探索エンジン（解析用）。空きマス12以下の終盤は完全読み
- `othello/analyze.py` — 弱点解析：自分の全手を「最善手との石差」で評価し、悪手とフェーズ別（序盤／中盤／終盤）の損失を集計
- `play.py` — ターミナルでAIと対戦（レベル1〜4）。終局後に棋譜を `games/` に保存し、弱点サマリを表示
- `analyze_game.py` — 棋譜（オセロクエスト形式の文字列、またはファイル）を解析してレポートを出力
- `selfplay.py` — AI同士の対戦（動作確認・デモ）
- `games/sample-game-001.txt` — サンプル棋譜（2026-11-26の対局、白の敗北 27-37）
- `tests/` — エンジンと解析のテスト

## 使い方

対戦する：

```bash
python3 play.py --color white --level 2
```

対局を解析する：

```bash
python3 analyze_game.py --file games/sample-game-001.txt --color white
python3 analyze_game.py --kifu E6F4E3... --color black --out report.md
```

テスト：

```bash
python3 -m unittest discover -s tests
```

## 解析の考え方

- 各手について、エンジンが「打った手の評価値」と「最善手の評価値」の差（損失）を計算します
- 終盤（空きマス12以下）は完全読みなので石差は正確です。中盤以前は深さ制限つき探索の推定値で、レポートにも「推定」と明記されます
- 損失6石以上を悪手として、序盤（1〜20手）／中盤（21〜44手）／終盤（45手〜）に分けて集計します。どのフェーズで石を失っているかを見るのが目的です
- 1局の解析には1〜2分程度かかります

## Web版（ブラウザ対戦）

`web/` にブラウザで対戦できるWeb版があります。ビルド不要の静的サイトです。

ローカルで開く：

```bash
cd web && python3 -m http.server 8000
# http://localhost:8000 を開く
```

- 色（黒／白）とAIレベル（1〜4）を選んで対戦できます。合法手は盤上に表示されます
- 終局後に棋譜（オセロクエスト形式）が表示され、コピーして解析ツールやチャット分析に使えます
- 「待った」で直前の自分の手を取り消せます
- 「結果をメールで送信」ボタンで、棋譜・自分の色・結果が入ったメール（宛先 muse-yuki0831@muse.ai）が開き、送信すると解析が始まります

## 定石トレーナー（Web版）

`web/joseki/` に、定石を覚えるための学習・テストアプリがあります（公開時は `/joseki/`）。

- 学習モード：10定石（虎・猫・兎・野兎・燕・河馬・犬・牛・羊・鼠）を盤面で再生しながら、特徴と覚え方のコツで覚える
- テストは3形式ミックス：「次の一手」「手順再現」「名前当て」
- 定石ごとに正解履歴を記録し、「覚えた／学習中／未テスト」に自動分類。間隔反復（Leitner方式、1日→3日→7日→14日→30日）で再出題のタイミングを管理する
- 「今日のテスト」で、期限が来た定石と弱い定石から毎日5問が自動で出題される
- 記録はブラウザの localStorage に保存される（端末ごと）

### 対局結果をメールで送って解析する

オセロクエストなどの対局も、自分のGmailから **muse-yuki0831@muse.ai** 宛に
棋譜と自分の色（黒／白）を書いて送れば、解析してチャットで報告します。

### Vercelへのデプロイ

リポジトリ直下の `vercel.json` で出力ディレクトリを `web/` に指定済みです。
Vercelでこのリポジトリを Import すれば、設定変更なしでそのままデプロイできます
（Framework Preset は Other のままで問題ありません）。

## サンプル棋譜の解析結果（要点）

白（後手）の敗因は終盤に集中していました。

- 54手目 G2（正解 G1）：14石損— ここで勝敗が決まった
- 46手目 A8（正解 H5）：完全読みでは18石損（本ツールの推定では8石損と控えめに出ます）

この2手は成長アプリの終盤ドリル第1問・第2問にもなっています。
